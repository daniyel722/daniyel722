\# ☸️ تمپلیت ساخت کلاستر کوبرنیتیز (GKE)



این تمپلیت شامل یک اسکریپت Bash متغیرپذیر است که به شما کمک می‌کند با استفاده از محیط Cloud Shell، به سرعت یک کلاستر کوبرنیتیز (GKE) در گوگل کلود راه‌اندازی کنید.



\## ⚙️ راهنمای تنظیمات متغیرها

پیش از اجرای اسکریپت، متغیرهای موجود در بالای فایل `create-gke-template.sh` را بر اساس نیاز سناریو یا آزمون خود تغییر دهید:



\* \*\*نام کلاستر (`CLUSTER\_NAME`)\*\*: نامی که برای کلاستر کوبرنیتیز در نظر گرفته‌اید.

\* \*\*زون (`ZONE`)\*\*: منطقه جغرافیایی استقرار کلاستر (مثلاً `us-central1-a`).

\* \*\*تعداد نودها (`NUM\_NODES`)\*\*: تعداد ماشین‌های مجازی (Worker Nodes) در کلاستر.

\* \*\*نوع ماشین (`MACHINE\_TYPE`)\*\*: قدرت پردازشی نودها (برای تست‌ها معمولاً `e2-medium` استفاده می‌شود).



\*نکته: این اسکریپت به صورت خودکار دستور `get-credentials` را نیز اجرا می‌کند تا بتوانید بلافاصله پس از اتمام ساخت، از دستورات `kubectl` استفاده کنید.\*
