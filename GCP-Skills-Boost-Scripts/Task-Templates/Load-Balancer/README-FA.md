\# ⚖️ تمپلیت ساخت لود بالانسر (HTTP Load Balancer)



این تمپلیت شامل یک اسکریپت Bash متغیرپذیر است که شش مرحله طولانی ساخت Load Balancer را در گوگل کلود به صورت کاملاً خودکار انجام می‌دهد.



\## ⚙️ راهنمای تنظیمات متغیرها

پیش از اجرای این اسکریپت، باید یک \*\*Instance Group\*\* (گروه ماشین‌های مجازی) از قبل ساخته باشید. سپس متغیرهای بالای فایل `create-lb-template.sh` را تنظیم کنید:



\* \*\*گروه ماشین‌ها (`INSTANCE\_GROUP`)\*\*: نام دقیق Instance Group که قرار است ترافیک به سمت آن هدایت شود.

\* \*\*زون (`ZONE`)\*\*: منطقه‌ای که Instance Group شما در آن قرار دارد.

\* \*\*پورت (`PORT`)\*\*: پورتی که ترافیک روی آن جریان دارد (معمولاً `80`).

\* سایر متغیرها (مثل نام Health Check یا URL Map) را می‌توانید به شکل پیش‌فرض رها کنید، مگر اینکه در صورت‌مسئله آزمون نام‌های خاصی از شما خواسته شده باشد.
