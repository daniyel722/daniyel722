\# 🖥️ تمپلیت ساخت ماشین مجازی (Compute Engine)



این تمپلیت شامل یک اسکریپت Bash متغیرپذیر است که به شما کمک می‌کند با استفاده از محیط Cloud Shell و دستورات `gcloud`، به سرعت یک ماشین مجازی (VM) در گوگل کلود بسازید.



\## ⚙️ راهنمای تنظیمات متغیرها

پیش از اجرای اسکریپت، متغیرهای موجود در بالای فایل `create-vm-template.sh` را بر اساس نیاز سناریو یا آزمون خود تغییر دهید:



\* \*\*نام ماشین (`INSTANCE\_NAME`)\*\*: نام ماشین مجازی شما.

\* \*\*زون (`ZONE`)\*\*: منطقه جغرافیایی (مثلاً `us-central1-a`).

\* \*\*نوع ماشین (`MACHINE\_TYPE`)\*\*: قدرت پردازشی ماشین (مثلاً `e2-micro` برای تسک‌های سبک).

\* \*\*تگ‌ها (`TAGS`)\*\*: تگ‌های شبکه برای اتصال فایروال (مثلاً `http-server`).

\* \*\*بدون آی‌پی پابلیک (`no-address--`)\*\*: این فلگ برای امنیت بیشتر (مثل ساخت Bastion Host) قرار داده شده است. در صورتی که ماشین شما به اینترنت خارجی نیاز دارد، این خط را از انتهای کد حذف کنید.
