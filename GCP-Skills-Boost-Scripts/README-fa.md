\# ☁️ اسکریپت‌های اتوماسیون گوگل کلود (Google Cloud Skills Boost)



به مخزن اتوماسیون ابری من خوش آمدید! این مجموعه شامل اسکریپت‌های Bash متغیرپذیر و راهنماهای گام‌به‌گام است که برای سرعت بخشیدن به حل چالش‌ها و آزمون‌های Google Cloud Skills Boost (مانند GSP304، GSP305 و غیره) با استفاده از Cloud Shell طراحی شده‌اند.



\## 📂 ساختار ریپازیتوری



این مخزن به صورت ماژولار طراحی شده است تا به راحتی به کدهای پایه و سناریوها دسترسی داشته باشید:



| دسته بندی / تسک | توضیحات | لینک پوشه |

| :--- | :--- | :--- |

| \*\*ماشین مجازی (VM)\*\* | اسکریپت خودکار برای ساخت و کانفیگ سریع Compute Engine | \[مشاهده پوشه](./2-Task-Templates/Compute-Engine-VM/) |

| \*\*کوبرنیتیز (GKE)\*\* | اسکریپت راه‌اندازی سریع کلاستر GKE و دریافت کریدنشال | \[مشاهده پوشه](./2-Task-Templates/GKE-Kubernetes/) |

| \*\*لود بالانسر (Load Balancer)\*\* | اسکریپت چندمرحله‌ای ساخت HTTP Load Balancer | \[مشاهده پوشه](./2-Task-Templates/Load-Balancer/) |

| \*\*شبکه و فایروال (VPC)\*\* | ساخت شبکه سفارشی، ساب‌نت و رول‌های فایروال | \[مشاهده پوشه](./2-Task-Templates/VPC-and-Firewall/) |

| \*\*چالش‌های ازمون (Challenge Labs)\*\* | راه‌حل‌های کامل و گام‌به‌گام برای آزمون‌های خاص GSP | \[مشاهده پوشه](./1-Challenge-Labs/) |



\## 🚀 نحوه استفاده

۱. ریپازیتوری را در محیط Google Cloud Shell باز کنید.

۲. وارد پوشه تسک یا چالش مورد نظروید.

۳. متغیرهای موجود در بالای فایل `.sh` را بر اساس نیاز آزمایشگاه خود ویرایش کنید.

۴. اسکریپت را اجرایی کرده (`chmod +x`) و اجرا کنید (`./script.sh`).
