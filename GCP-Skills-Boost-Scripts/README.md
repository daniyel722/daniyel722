\# ☁️ Google Cloud Skills Boost Automation Scripts



Welcome to my personal cloud automation repository! This collection contains parameterized Bash scripts and step-by-step guides designed to rapidly deploy and solve Google Cloud Skills Boost challenges (such as GSP301, GSP304, GSP305, etc.) using Cloud Shell.



\## 📂 Repository Structure



The repository is divided into modular task templates and challenge labs:



| Category / Task | Description | Directory Link |

| :--- | :--- | :--- |

| \*\*Compute Engine VM\*\* | Automated script to deploy and configure virtual machines. | \[View Folder](./2-Task-Templates/Compute-Engine-VM/) |

| \*\*GKE Kubernetes\*\* | Rapid deployment script for GKE clusters and node pools. | \[View Folder](./2-Task-Templates/GKE-Kubernetes/) |

| \*\*Load Balancer\*\* | Full pipeline script to set up HTTP(S) Load Balancers. | \[View Folder](./2-Task-Templates/Load-Balancer/) |

| \*\*VPC \& Firewall\*\* | Custom network, subnet, and firewall rule configurations. | \[View Folder](./2-Task-Templates/VPC-and-Firewall/) |

| \*\*Challenge Labs\*\* | Step-by-step complete solutions for specific GSP badges. | \[View Folder](./1-Challenge-Labs/) |



\## 🚀 How to Use

1\. Clone or open your repository in Google Cloud Shell.

2\. Navigate to the desired task or challenge folder.

3\. Edit the variables at the top of the `.sh` script to match your lab requirements.

4\. Make the script executable (`chmod +x script.sh`) and run it (`./script.sh`).
